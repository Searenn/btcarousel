# btcarousel — опубликованная версия

Ветка `gh-pages` обслуживает https://searenn.github.io/btcarousel/.

## studio v9

В меню выделенного текста доступны пять форм цветового выделения: скруглённое, прямоугольное, смещённый блок, маркер и подчёркивание. Ползунки регулируют горизонтальные/вертикальные отступы, радиус углов и смещение. Изменения относятся к выбранному фрагменту, сохраняются в проекте и одинаково отображаются в редакторе и DOM для JPG/MP4. Чтобы открыть меню, дважды кликните блок, выделите слова мышью; меню появляется после выделения или по правой кнопке.

- Кнопка «Соцсети» под превью включает общий текстовый блок на всех слайдах. Клик по блоку открывает обычный тулбар оформления; двойной клик — обычный редактор текста. Доступны размер, жирность, курсив, выравнивание, цвета, подложка, прозрачность, скругление, эффекты и обводка. Угол блока меняет размер; сам блок можно перетаскивать. Настройки общие для всей карусели.
- Оформление соцсетей убрано из боковой панели. Блок использует тот же компонент и обработчики, что обычные текстовые блоки. Плашки старых проектов автоматически отображаются в новом редакторе с сохранением текста, цветов и позиции.
- Темы оформляют карточки текста. Убраны сетки, звёзды, бумажные текстуры и прочие декоративные фоны. Загруженные картинки, их масштаб и смещение сохраняются при смене темы; рамки исходных золотой и изумрудной тем также не накладываются поверх картинок.
- Всего 28 тем. Новые 10: СЛР — «Первое свидание», «Переписка в полночь», «Твой сосед», «После пар», «Между нами»; дарк-романс — «Одержимость», «Под запретом», «По лезвию», «Тихая угроза»; романтическое фэнтези — «Клятва тьме».
- У эффекта текста «Обводка» есть толщина 0–6 px и цвет; 0 отключает обводку. Работает для обычных блоков и соцсетей.
- Поддерживаются 3:4 и 9:16, сохранение в проекте/localStorage/JSON, JPG и MP4 через общий компонент слайдов.

## Воспроизводимая сборка

```sh
npm ci
npm test
npm run build
```

`studio/highlights.jsx` содержит форматирование выделений и его сериализацию, `studio/features.jsx` — новые компоненты и адаптер общего блока, `studio/themes.jsx` — определения тем. `scripts/build.mjs` интегрирует их в точную опубликованную версию studio v7, проверяя её Git blob SHA и уникальность каждой точки интеграции. Результат: `assets/btcarousel-studio-v9.js` и ссылка на него в `index.html`.

Опубликованная studio v7 новее исходников в `main`: она содержит плоские маркеры, инструменты объектов, автоподгонку, эффекты фона/текста и исправления шрифтов. Сборка расширяет опубликованную версию, сохраняя эти функции. Предыдущие assets оставлены как база и возможность отката.

Тесты запускают весь редактор в JSDOM: общий блок соцсетей и обычный тулбар, редактирование, перемещение, изменение размера, сохранение/импорт, оба формата, настройки обводки, сохранность маркеров/инструментов, отсутствие декора поверх пользовательских фото во всех 28 темах. Это проверка редактора и DOM для экспорта, а не визуальная проверка в браузере или запись MP4.
