# btcarousel — опубликованная версия

Ветка `gh-pages` обслуживает https://searenn.github.io/btcarousel/.

## Доработки studio v8

- Общая плашка соцсетей: включение/выключение, свой текст, размер, ширина, цвета; перетаскивание и стрелки. Положение общее для всех слайдов. Плашка сохраняется в проекте, localStorage и JSON, включается в JPG и MP4.
- У эффекта текста «Обводка» появились толщина 0–6 px и цвет. Толщина 0 отключает обводку. Параметры каждого блока независимы.
- Восемь новых тем: «Личный дневник», «Поп-комикс», «Ночной киносеанс», «Неоновый терминал», «Тайное общество», «Коллаж воспоминаний», «Журнальная полоса», «Лунное таро».
- Поддерживаются оба формата: 3:4 и 9:16. Темы сохраняют текст, положение блоков и настройки проекта.

## Воспроизводимая сборка

```sh
npm ci
npm test
npm run build
```

`studio/features.jsx` содержит новые компоненты, `studio/themes.jsx` — определения тем. `scripts/build.mjs` интегрирует их в точную опубликованную версию studio v7, проверяя её Git blob SHA и уникальность каждой точки интеграции. Результат: `assets/btcarousel-studio-v8.js` и ссылка на него в `index.html`.

Опубликованная studio v7 новее исходников в `main`: она содержит плоские маркеры, инструменты объектов, автоподгонку, эффекты фона/текста и исправления шрифтов. Поэтому сборка расширяет опубликованную версию, сохраняя её функции. Исходный v7-asset оставлен неизменным как база и возможность отката.

Тесты запускают весь редактор в JSDOM: плашка, перемещение, сохранение, импорт, оба формата, настройки обводки, прежние маркеры/инструменты и декор всех новых тем в превью и DOM для экспорта. Они не заменяют визуальную проверку в браузере и запись MP4.
